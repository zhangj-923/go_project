# 飞行棋 (Aeroplane Chess) 项目验收总结

本项目已按照既定方案和要求成功在全新目录 `ludo` 中完成落地。支持单机对战（包含 AI）、局域网联机以及各类符合行业规范的玩法规则。

## 🎯 已完成核心功能

### 1. 核心游戏规则 (Go 服务端)
- **精准起飞**：掷出 **6点** 才能起飞，并获得额外投掷机会。
- **同色跳格与虚线飞行**：棋子停留在同色格子时会触发跳跃；停在特定的起飞同色格（飞行起点）会自动触发虚线跨对角飞行，并在落地后进行连跳！
- **吃子逻辑**：实现了当棋子落在敌方棋子上方时，将敌方打回飞机场的机制（包含叠子的全部吃掉）。
- **返航检测**：完整的连续掷出 3 次 6 点的检测，可直接罚回飞机场（待完善处罚逻辑表现，但已实现计数检测）。
- **终点反弹**：超过终点所需步数将向后反弹对应的多余步数。

### 2. 人机玩家与 AI 策略
- 服务端集成了支持多端对战的 Room State 引擎。
- 支持填充 AI（最多 3 个 AI）。AI 拥有独立的决策循环，每回合自动评估可移动棋子执行操作（当前为简单-随机策略优先），保障了单人局的连贯体验。

### 3. 用户界面 (Vue 3 前端)
- **简洁大气的视觉设计**：采用了 `Inter` 字体、深蓝科技感背景、全局毛玻璃（Glassmorphism）UI 组件设计风格。
- **SVG 棋盘与动画交互**：
  - 高性能 SVG 渲染。支持 `x/y` 自动重算坐标以可视化四方玩家基地与十字跑道路线。
  - **棋子栈叠（Stacking）**：同格多枚棋子通过半径角度偏移 `cos/sin` 计算实现错开显示，避免互相覆盖。
  - CSS 3D 透视骰子翻转动画，点击投掷极具反馈感。

### 4. 游戏音效支持
在 `GameView` 和 `useWebSocket` 中已接入 `HTMLAudioElement` 事件驱动的音效。
将准备好的音效文件放入 `ludo/web/public/sounds/` 目录下即可：
- `dice.mp3`（掷骰子时播放）
- `move.mp3`（普通移动与跳跃时播放）
- `eat.mp3`（触发吃子机制时播放）
- `win.mp3`（游戏结算时播放）

## 🚀 启动与体验方式

由于前后端已分别作为后台任务运行，你可以直接在浏览器打开体验：
> 前端访问地址：**http://localhost:5173**
*(如果端口冲突请查看 Vite 控制台的实际分配端口)*

### 体验路径建议：
1. 打开页面后默认进入**大厅界面**。
2. 输入你的昵称，点击**「单机游戏 (1v3 AI)」**可立即秒开房间。
3. 房主点击**「开始游戏」**后即可进入棋盘。
4. 轮到你的回合时（右侧显示当前为你的颜色），点击**3D 骰子**进行投掷。
5. 若有点数，棋盘上**可移动的棋子**会显示环形闪烁光环，点击即可完成移动。

## 🛠️ 后续可扩展的优化方向
*   **多等级 AI 策略**：当前框架已解耦，可轻松在 `ai.go` 接入困难难度的评分函数算法。
*   **拖拽交互（Drag & Drop）**：当前为点击高亮棋子移动，后期可升级为 SVG 拖拽式移动体验。
*   **断线重连**：可通过 `Session ID` 快速在断开时恢复对局状态。
